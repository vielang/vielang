Cửa hàng cần thêm bảng mã giảm giá. Mã không được trùng, phần trăm giảm chỉ
từ 1 đến 50. Nếu chỉ kiểm tra trong code thì một chỗ quên kiểm tra là dữ liệu
sai lọt vào. Ràng buộc để database tự chặn.

## Khái niệm

🏗️ **CREATE TABLE**: câu lệnh tạo bảng mới, khai báo tên cột, kiểu dữ liệu và ràng buộc của từng cột.

🛡️ **Ràng buộc (constraint)**: quy tắc database tự kiểm tra mỗi lần thêm hay sửa dữ liệu, dữ liệu vi phạm bị từ chối.

| Ràng buộc | Ý nghĩa |
|---|---|
| `PRIMARY KEY` | khoá chính: không trùng, không NULL |
| `NOT NULL` | bắt buộc có giá trị |
| `UNIQUE` | không được trùng |
| `CHECK (điều kiện)` | giá trị phải thoả điều kiện |
| `REFERENCES bảng (cột)` | khoá ngoại |

`DEFAULT giá_trị` không phải ràng buộc, nhưng hay đi kèm: cột không được ghi
khi `INSERT` thì nhận giá trị này.

## Ví dụ

```sql
CREATE TABLE coupons (
  coupon_id NUMBER GENERATED BY DEFAULT AS IDENTITY
            PRIMARY KEY,
  code      VARCHAR2(20) NOT NULL UNIQUE,
  percent   NUMBER NOT NULL
            CHECK (percent BETWEEN 1 AND 50),
  active    NUMBER(1) DEFAULT 1 NOT NULL
);
```

- `code` bắt buộc có và không trùng.
- `CHECK (percent BETWEEN 1 AND 50)` chặn mọi giá trị ngoài khoảng.
- `active` mặc định là 1. Oracle 19c chưa có kiểu `BOOLEAN` cho cột, nên
  thường dùng `NUMBER(1)` với 1 là có, 0 là không.

## Thử ngay

```sql
CREATE TABLE coupons (
  coupon_id NUMBER GENERATED BY DEFAULT AS IDENTITY
            PRIMARY KEY,
  code      VARCHAR2(20) NOT NULL UNIQUE,
  percent   NUMBER NOT NULL
            CHECK (percent BETWEEN 1 AND 50),
  active    NUMBER(1) DEFAULT 1 NOT NULL
);

INSERT INTO coupons (code, percent) VALUES ('SALE10', 10);

SELECT coupon_id, code, percent, active FROM coupons;
```

**Đoán trước khi chạy:** câu `INSERT` không ghi `coupon_id` và `active`. Hai
cột này có giá trị gì?

<details>
<summary>Xem kết quả</summary>

| COUPON_ID | CODE | PERCENT | ACTIVE |
|---|---|---|---|
| 1 | SALE10 | 10 | 1 |

`coupon_id` do identity cấp là 1. `active` lấy giá trị `DEFAULT` là 1.

## Lỗi hay gặp

**Thêm dữ liệu vi phạm `CHECK`.** Oracle báo lỗi `ORA-02290`: vi phạm ràng
buộc kiểm tra.

```sql
-- SAI — lỗi: 80% nằm ngoài khoảng 1 đến 50
CREATE TABLE coupons (
  code    VARCHAR2(20) NOT NULL,
  percent NUMBER CHECK (percent BETWEEN 1 AND 50)
);
INSERT INTO coupons (code, percent) VALUES ('BIG', 80);
```

**Khai báo `VARCHAR2(n)` rồi lưu chữ tiếng Việt.** Mặc định `n` tính theo
**byte**, mà chữ có dấu như "ũ" chiếm 2 byte. "Dũng" có 4 chữ nhưng tới 5
byte, nên Oracle báo lỗi `ORA-12899`: giá trị quá dài.

```sql
-- SAI — lỗi: 'Dũng' cần 5 byte
CREATE TABLE staff (name VARCHAR2(4));
INSERT INTO staff (name) VALUES ('Dũng');
```

```sql
-- ĐÚNG — thêm CHAR để tính theo số ký tự
CREATE TABLE staff (name VARCHAR2(4 CHAR));
INSERT INTO staff (name) VALUES ('Dũng');
```

## Tóm tắt

- `CREATE TABLE` khai báo cột, kiểu dữ liệu và ràng buộc.
- Ràng buộc để database tự chặn dữ liệu sai: `NOT NULL`, `UNIQUE`, `CHECK`,
  khoá chính, khoá ngoại.
- `DEFAULT` cho cột giá trị sẵn khi `INSERT` không ghi tới.
- Lưu tiếng Việt thì dùng `VARCHAR2(n CHAR)` để tính theo số ký tự.
