Dữ liệu trong một `List<Product>` của chương trình C# mất khi chương trình
tắt. Dữ liệu của cửa hàng phải còn nguyên, và nhiều người phải đọc và ghi cùng lúc mà
không giẫm lên nhau. Việc đó do database đảm nhận. Khoá học này dùng Oracle,
loại database phổ biến ở ngân hàng và doanh nghiệp lớn.

## Khái niệm

🗄️ **Database quan hệ (relational database)**: nơi lưu dữ liệu thành nhiều bảng, các bảng liên kết với nhau qua khoá.

📋 **Bảng (table)**: tập hợp các dòng cùng cấu trúc, mỗi cột là một loại thông tin, mỗi dòng là một đối tượng.

🔑 **Khoá chính (primary key)**: cột có giá trị không trùng và không được trống, dùng để chỉ đúng một dòng.

💬 **SQL**: ngôn ngữ dùng để đọc và thay đổi dữ liệu trong database quan hệ.

Bảng giống class, cột giống property, mỗi dòng giống một object.

## Ví dụ

Một bảng sản phẩm đơn giản được tạo như sau:

```sql
CREATE TABLE product_samples (
  product_id NUMBER PRIMARY KEY,
  name       VARCHAR2(100) NOT NULL,
  price      NUMBER(12, 2) NOT NULL
);
```

- Mỗi dòng trong ngoặc là một cột: tên cột, kiểu dữ liệu, rồi quy tắc.
- `PRIMARY KEY`: `product_id` là khoá chính.
- `NOT NULL`: cột này bắt buộc phải có giá trị.

Ba kiểu dữ liệu hay dùng nhất trong Oracle:

| Kiểu | Chứa gì | Ví dụ |
|---|---|---|
| `NUMBER` | số nguyên hoặc số thực | `120`, `5000.50` |
| `VARCHAR2(n)` | chuỗi tối đa n byte | `'Bút bi'` |
| `DATE` | ngày giờ | `DATE '2025-01-05'` |

Chuỗi trong SQL đặt trong dấu nháy **đơn**: `'Bút bi'`.

## Cài Oracle trên máy

Khoá học này, chương EF Core của khoá ASP.NET Core và khoá WinForms dùng chung
một Oracle chạy bằng Docker. Cài **Docker Desktop**, rồi chạy lệnh sau một lần:

```bash
docker run -d --name oracle -p 1521:1521 -e ORACLE_PASSWORD=oracle_pw -e APP_USER=shop -e APP_USER_PASSWORD=shop_pw gvenzl/oracle-free:slim-faststart
```

- Lệnh tải Oracle Database Free và tạo sẵn user `shop`, mật khẩu `shop_pw`.
- `ORACLE_PASSWORD` là mật khẩu của user quản trị `system`, khoá ASP.NET Core
  sẽ dùng đến.
- Lần đầu mất vài phút. Chạy `docker logs -f oracle`, thấy dòng
  `DATABASE IS READY TO USE!` là dùng được.
- Tắt máy xong, bật lại bằng `docker start oracle`.

Để gõ SQL, cài VS Code và extension **Oracle SQL Developer**. Tạo kết nối mới
với user `shop`, mật khẩu `shop_pw`, host `localhost`, port `1521`,
service name `FREEPDB1`.

```sql reset
      'DROP TABLE "' || t.table_name || '" CASCADE CONSTRAINTS';
  END LOOP;
END;
```

## Thử ngay

Chạy câu lệnh sau bằng kết nối `shop`:

```sql
SELECT * FROM products ORDER BY product_id;
```

`SELECT *` lấy mọi cột. `ORDER BY` sắp kết quả theo mã, bài Sắp xếp sẽ nói kỹ hơn.

## Lỗi hay gặp

**Thêm dòng trùng khoá chính.** `INSERT` thêm một dòng mới (học kỹ ở chương
Thay đổi dữ liệu). Khoá chính không được trùng, nên Oracle báo lỗi
`ORA-00001`: vi phạm ràng buộc không trùng.

```sql
-- SAI — lỗi: đã có sản phẩm mã 1
INSERT INTO products (product_id, name, price, stock)
  VALUES (1, 'Kéo', 15000, 10);
```

```sql
-- ĐÚNG — không ghi mã, để Oracle tự cấp
INSERT INTO products (name, price, stock)
  VALUES ('Kéo', 15000, 10);
```

Thử xong, chạy `ROLLBACK;` để bỏ dòng Kéo (bài Transaction sẽ giải thích).

## Tóm tắt

- Database quan hệ lưu dữ liệu thành nhiều bảng liên kết với nhau.
- Mỗi bảng có cột (loại thông tin) và dòng (từng đối tượng).
- Khoá chính không trùng, không trống, dùng để chỉ đúng một dòng.
- Oracle hay dùng `NUMBER`, `VARCHAR2`, `DATE`. Chuỗi đặt trong nháy đơn.
